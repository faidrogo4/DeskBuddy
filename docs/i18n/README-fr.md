## Fonctionnalités

- Aperçu en temps réel (WYSIWYG) et interface propre et simple pour une expérience d'écriture sans distraction.
- Prise en charge de [CommonMark Spec](https://spec.commonmark.org), [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) et prise en charge sélective de [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- Extensions Markdown telles que les expressions mathématiques (KaTeX), le front matter et les emojis.
- Raccourcis de paragraphe et de style en ligne pour améliorer votre efficacité d'écriture.
- Export de fichiers **HTML** et **PDF**.
- Divers [thèmes](../../packages/website/content/docs/end-user/THEMES.md) : **Cadmium Light**, **Material Dark**, etc.
- Divers modes d'édition : **mode code source**, **mode machine à écrire**, **mode focus**.
- Coller des images directement depuis le presse-papiers.

Vous voulez voir les nouvelles fonctionnalités de la dernière version ? Consultez le [CHANGELOG](../../packages/website/content/docs/CHANGELOG.md).

#### macOS

Téléchargez le dernier `deskbuddy-mac-(arm64|x64)-%version%.dmg` depuis la [page de releases](https://github.com/faidrogo4/DeskBuddy/releases/latest).

#### Windows

Téléchargez et installez simplement DeskBuddy via l'assistant d'installation (`deskbuddy-win-(x64|arm64)-%version%-setup.exe`) et choisissez entre une installation par utilisateur ou pour tout le système.

#### Linux

Veuillez suivre les [instructions d'installation Linux](../../packages/website/content/docs/end-user/INSTALLATION.md).

#### Autres

Tous les binaires pour Linux, macOS et Windows peuvent être téléchargés depuis la [page de releases](https://github.com/faidrogo4/DeskBuddy/releases/latest). Si une version n'est pas disponible pour votre système, veuillez ouvrir un [issue](https://github.com/faidrogo4/DeskBuddy/issues).
