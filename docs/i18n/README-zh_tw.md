## 功能

- 即時預覽（所見即所得）及簡潔清爽的界面，帶來無干擾的寫作體驗。
- 支援 [CommonMark 規範](https://spec.commonmark.org)、[GitHub Flavored Markdown 規範](https://github.github.com/gfm/)，並選擇性支援 [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown)。
- 支援數學表達式（KaTeX）、Front Matter 和表情符號等 Markdown 擴展。
- 支援段落和內聯樣式快捷方式，提升寫作效率。
- 可匯出 **HTML** 和 **PDF** 文件。
- 多種[主題](../../packages/website/content/docs/end-user/THEMES.md)：**Cadmium Light**、**Material Dark** 等。
- 多種編輯模式：**原始碼模式**、**打字機模式**、**專注模式**。
- 支援直接從剪貼簿貼上圖片。

想瞭解最新版本的新功能？請參閱 [CHANGELOG](../../packages/website/content/docs/CHANGELOG.md)。

#### macOS

從[發布頁](https://github.com/faidrogo4/DeskBuddy/releases/latest)下載最新的 `deskbuddy-mac-(arm64|x64)-%version%.dmg`。

#### Windows

只需下載並通過安裝嚮導（`deskbuddy-win-(x64|arm64)-%version%-setup.exe`）安裝 DeskBuddy，並選擇使用者級或系統級安裝。

#### Linux

請參閱 [Linux 安裝說明](../../packages/website/content/docs/end-user/INSTALLATION.md)。

#### 其他

所有 Linux、macOS 和 Windows 的二進位文件均可從[發布頁](https://github.com/faidrogo4/DeskBuddy/releases/latest)下載。如果你的系統沒有對應版本，請提交 [issue](https://github.com/faidrogo4/DeskBuddy/issues)。
