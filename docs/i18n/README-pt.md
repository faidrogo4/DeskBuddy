## Recursos

- Visualização em tempo real (WYSIWYG) e interface limpa e simples para uma experiência de escrita sem distrações.
- Suporte a [CommonMark Spec](https://spec.commonmark.org), [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) e suporte seletivo a [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- Extensões Markdown como expressões matemáticas (KaTeX), front matter e emojis.
- Suporte a atalhos de parágrafo e estilo inline para melhorar sua eficiência de escrita.
- Exportação de arquivos **HTML** e **PDF**.
- Vários [temas](../../packages/website/content/docs/end-user/THEMES.md): **Cadmium Light**, **Material Dark** etc.
- Vários modos de edição: **Modo Código-Fonte**, **Modo Máquina de Escrever**, **Modo Foco**.
- Cole imagens diretamente da área de transferência.

Quer ver os novos recursos da última versão? Consulte o [CHANGELOG](../../packages/website/content/docs/CHANGELOG.md).

#### macOS

Baixe o último `deskbuddy-mac-(arm64|x64)-%version%.dmg` da [página de releases](https://github.com/faidrogo4/DeskBuddy/releases/latest).

#### Windows

Simplesmente baixe e instale o DeskBuddy via assistente de configuração (`deskbuddy-win-(x64|arm64)-%version%-setup.exe`) e escolha instalar por usuário ou para toda a máquina.

#### Linux

Por favor siga as [instruções de instalação do Linux](../../packages/website/content/docs/end-user/INSTALLATION.md).

#### Outros

Todos os binários para Linux, macOS e Windows podem ser baixados da [página de releases](https://github.com/faidrogo4/DeskBuddy/releases/latest). Se uma versão não estiver disponível para o seu sistema, por favor abra um [issue](https://github.com/faidrogo4/DeskBuddy/issues).
