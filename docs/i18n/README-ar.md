## الميزات

- معاينة فورية (WYSIWYG) وواجهة نظيفة وبسيطة للحصول على تجربة كتابة خالية من الإلهاء.
- دعم [مواصفات CommonMark](https://spec.commonmark.org)، [مواصفات GitHub Flavored Markdown](https://github.github.com/gfm/) ودعم انتقائي لـ [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- امتدادات ماركداون مثل التعبيرات الرياضية (KaTeX) وfront matter والرموز التعبيرية.
- دعم اختصارات الفقرات والأساليب المضمنة لتحسين كفاءة الكتابة.
- إخراج ملفات **HTML** و**PDF**.
- سمات متنوعة [themes](../../packages/website/content/docs/end-user/THEMES.md): **Cadmium Light**، **Material Dark** وغيرها.
- أوضاع تحرير متنوعة: **وضع الكود المصدري**، **وضع الآلة الكاتبة**، **وضع التركيز**.
- لصق الصور مباشرة من الحافظة.

هل تريد الاطلاع على الميزات الجديدة لأحدث إصدار؟ يرجى الرجوع إلى [CHANGELOG](../../packages/website/content/docs/CHANGELOG.md).

#### macOS

يمكنك تنزيل أحدث `deskbuddy-mac-(arm64|x64)-%version%.dmg` من [صفحة الإصدارات](https://github.com/faidrogo4/DeskBuddy/releases/latest).

#### Windows

ما عليك سوى تنزيل وتثبيت DeskBuddy عبر معالج الإعداد (`deskbuddy-win-(x64|arm64)-%version%-setup.exe`) واختيار ما إذا كنت تريد التثبيت لكل مستخدم أو على مستوى الجهاز.

#### Linux

يرجى اتباع [تعليمات تثبيت Linux](../../packages/website/content/docs/end-user/INSTALLATION.md).

#### أنظمة أخرى

يمكن تنزيل جميع الملفات الثنائية لنظام Linux وmacOS وWindows من [صفحة الإصدارات](https://github.com/faidrogo4/DeskBuddy/releases/latest). إذا لم يكن الإصدار متاحًا لنظامك، فيرجى فتح [مشكلة](https://github.com/faidrogo4/DeskBuddy/issues).
